List    - is data type which contains multiple value 
        - mutable (value can be changed)
        - Member of List will be accessed by index
        - Member of list will be updated by index
        - Members can be any kind of data (int,float,None,boolean,string)
        - List is bundle of int,float,None,boolean and String
        - List is indentified by PVM by [] symbol
        - List is created by list() constructor
        - Index start from '0'
        - Python supports both way indexing (L -> R & R->L)
        - Index is always absolute
        - List contains other list as well 
        - List contains other object like - tuple, disctionary,set etc

List's functions
        - append(value) - add member at the end 
        - insert(index,value) - add member at given index
        - extend() - extending one list to another
        - copy() - copy member from one list to another
        - remove(value) - remove member from the list
        - len() - show the lenght of list
        - sum() - summation of int,float member
        - del  - delete the list
        - count(value) - no of occurence of the member 


                        🚨Key Points🚨
                        
📌 Modifies in-place: The original list is directly changed, not a new one created.

📌 Single element only: insert() can only add one element at a time. To add multiple elements from an iterable, use the extend() method or list concatenation.

📌 Index behavior: If the specified index is larger than the list's length, the element is simply added to the end (like append()). If the index is a negative number that exceeds the list's length, the element is inserted at the beginning.

📌 Performance: Inserting elements into the beginning or middle of a large list can be slow (O(n) time complexity) because all subsequent elements must be shifted. Appending to the end is generally faster (O(1) amortized time complexity). For performance-critical applications involving frequent insertions at both ends, consider using the collections.deque object.
